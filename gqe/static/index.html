Keep your database up to date

For a database you've already built. Checks each source you've set up for anything new since last time, and (in the second mode) tries to fill in values that are still missing for games you already have. Sources you haven't set up are skipped with a note rather than stopping the rest.

"New games only" is quicker. "Fill gaps" also re-checks existing games for anything still missing (size, year, score, genre, price) — it can take a while on a large database, same as running the individual steps below, but only asks about what's actually missing.

Backup & transfer

Your whole database in one file — build it once, then restore it on any other computer instead of fetching everything again. API keys are not included; enter them again on the new computer.

Import your own data (CSV)

A CSV with an id column (the ID column in the table; enable it under Columns) plus any of: size, price, drm, release_date, orig_year, score, genres, category. Your values always take priority over automatic sources.

Sources

A suggested order, not a requirement: each group below builds on the one before it, so working from the top usually gets you the most for the least time and setup.

1. Bring in games

Adds games to your database. Safe to repeat — nothing gets duplicated.

GOG

No key needed. Adds every GOG game with its original release date, price, genres and DRM-free flag in one step.

(rate-limited by GOG: about 50 games per 20 s)

Steam account setup

Needed once, by both Steam actions below (bringing in games, and fetching sizes). The key is free and only used to list Steam's catalog; the add-on reads each game's details afterwards.

Add-on: checking…
Steam Web API key:
How to get a free Steam key (about 2 minutes)
  1. Open steamcommunity.com/dev/apikey and sign in to Steam.
  2. It asks for a "Domain Name": type anything, for example localhost. Agree to the terms and click Register.
  3. Copy the key it shows and paste it above, then Save key.

Steam may require your account to be unrestricted (roughly $5 spent on Steam) and Steam Guard on your phone. The key stays on this computer and is hidden in the log.

IGDB — add games

Free key. Imports every real game IGDB lists for the platforms you tick (main games, remakes, remasters, ports; not DLC, mods or bundles). Games you already have are not duplicated — they just get IGDB's year, genres and score. New games have no size until you fetch one from Steam or GOG.

How to get a free IGDB key (about 2 minutes)
  1. Open dev.twitch.tv/console/apps and sign in (a Twitch account works).
  2. Register an application: any name, any OAuth Redirect URL such as http://localhost, category "Application Integration".
  3. Copy the Client ID, generate a Client Secret, paste both above and Save keys.
PC alone can take a few minutes

Steam — add games

Needs the Steam account setup above (add-on and key). Lists every app on Steam and adds each real PC game — with a measured size, dates, genres and a Metacritic score when Steam has one — skipping DLC, soundtracks, tools and non-Windows apps. Useful for games no other source lists. Resumable and cancelable; a re-run only checks apps it hasn't settled yet.

Redump — console discs

No key. Download a system .dat (or its .zip) from redump.org/downloads for exact console disc sizes, regions and serials.

2. Fill in the essentials

Years, genres, scores, sizes and prices for games you already have.

IGDB — fill in details

Uses the IGDB key set up above. Fills year, genre and score for every game you already have on a platform IGDB covers.

Steam — sizes and prices

Uses the Steam account setup above. Three steps: link your games to Steam, test the result on a sample before committing to the rest, then fetch for everything.

RAWG — console gaps

Free key. Fills year, genre and score for console games your disc files don't carry.

How to get a free RAWG key (about 1 minute)
  1. Open rawg.io/apidocs and sign up (free).
  2. Your API key appears on that page (or under your account's API settings). Copy it.
  3. Paste it above and Save key.

Free for personal, non-commercial use. Data comes from RAWG.io, credited here and in exports as required by their terms.

3. Slower or narrower sources

Worth running eventually, but each has a reason to wait: a rate limit, a narrower scope, or both.

SteamSpy — review scores

No key. Review-based score (% positive) and genre tags for games already matched to Steam. Limited to one page a minute, so a full pass takes an hour or two. Only games with 10+ reviews get a score. Resumable.

Wikidata — console dates

No key. Free release dates for console games (PS1/PS2/PS3/PSP, GameCube, Wii, Xbox/360, Dreamcast, Saturn). The public endpoint throttles hard, so this only runs when you ask for it, never automatically. Partial coverage: games it doesn't know stay blank.
